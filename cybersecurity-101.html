WHAT IS CYBERSECURITY

Cybersecurity is the practice of protecting systems,networks,and data from unauthorized access,attacks,ordamage.

It’s essential because today’s world is digitally connected — from banking systems to defense infrastructure — and every connection is a potential target.

CIA TRIAD

Confidentiality

Ensures data is accessed only by authorized

Why Confidentiality is Important :

  • Prevents data leaks
  • Protects personal and sensitive information
  • Avoids identity theft and fraud

How Confidentiality is Achieved :

  • Passwords
  • Encryption
  • Access control
  • Biometrics (fingerprint, face ID)

Integrity

Integrity ensures that data remains accurate, complete, and unchanged unless modified by an authorized person.

Why Integrity is Important :

  • Prevents unauthorized modification
  • Maintains trust in data

Real-Life Examples :

  • Exam marks should not be altered
  • Bank balance must remain correct
  • Legal documents must stay original

How Integrity is Maintained :

  • File hashes
  • Checksums
  • Digital signatures

Availability

Ensures resources are accessible when needed.

Real-Life Examples :

  • Banking system working 24/7
  • Company website not crashing
  • Hospital systems available during emergencies

How Availability is Ensured :

  • Regular backups
  • DDoS protection
  • Load balancing

DIFFERENTIATE THREAT VULNERABILITY AND RISK

Term Definition Example
Threat A threat is anything that has the potential to cause harm to systems, data, or individuals. Malware, insider attack
Vulnerability A weakness that can be exploited by a threat Unpatched operating system
Risk The probability of loss when a threat exploits a vulnerability Ransomware attack on outdated systems

MAN IN THE MIDDLE ATTACK

How MITM Attack Works :

  1. User sends data
  2. Attacker intercepts data
  3. Attacker forwards data
  4. Neither user nor server knows

Common Types :

  • Wi-Fi eavesdropping
  • Session hijacking
  • ARP spoofing
  • DNS spoofing
  • SSL stripping

Impact :

  • Password theft
  • Bank fraud
  • Identity theft
  • Data manipulation

Prevention :

  • Use HTTPS
  • Avoid public Wi-Fi
  • Use VPN
  • Enable encryption
  • Keep systems updated

ZERO DAY

A Zero-Day attack exploits a software vulnerability that is unknown to the software developer and for which no patch or fix exists yet.

Why it is called Zero-Day :

  • Developers have zero days to fix the vulnerability
  • Attackers exploit it before anyone knows

How it Works :

  1. Unknown vulnerability exists
  2. Attacker discovers flaw
  3. Exploits it secretly
  4. Damage occurs before fix

Why it is Dangerous :

  • No immediate defense
  • Antivirus may not detect it
  • High success rate
  • Massive damage

Prevention :

  • Regular updates
  • IDS / IPS
  • Behavior-based tools
  • Network monitoring
  • Least-privilege access

DOMAINS

Network Security

Network Security focuses on protecting computer networks and the data moving through them from unauthorized access, attacks, and misuse.

  • Firewalls
  • IDS / IPS
  • VPN
  • Network monitoring

Application Security

Application Security involves protecting software and applications from vulnerabilities and attacks throughout their lifecycle.

  • SQL Injection
  • XSS
  • Broken authentication

Information Security

Information Security (InfoSec) focuses on protecting data and information from unauthorized access, modification, or destruction

  • Encryption
  • Access control
  • Backup and recovery

Cloud Security

Cloud Security refers to protecting data, applications, and services stored in cloud environments.

  • IAM
  • Encryption
  • Secure configurations
  • Continuous monitoring

Endpoint Security

Endpoint Security protects end-user devices that connect to a network.

  • Antivirus
  • Device encryption
  • Regular updates
  • EDR

DNS

DNS stands for Domain Name System. It acts like the phonebook of the Internet. Every device connected to the Internet has a unique address called an IP address. Computers use these IP addresses to find and communicate with each other.

How DNS Works (Step by Step)

  1. User request: You type a web address into your browser.
  2. DNS Resolver: Your computer sends this request to a DNS resolver.
  3. DNS Lookup: The resolver looks up the IP address.
  4. Response: IP address is returned.
  5. Connection: Browser connects to server.

HTTP in Detail

HTTP is the protocol used for communicating with web servers for transmitting webpage data such as HTML, images, videos, etc.

HTTPS

HTTPS is the secure version of HTTP. HTTPS data is encrypted and prevents man-in-the-middle attacks.

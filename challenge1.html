Challenge 1 – Source Code

Challenge Description

Developers sometimes leave sensitive information inside HTML comments, JavaScript files, or encoded data in the source code. Inspect the page source and scripts carefully to find hidden flags.

  • Easy: Find flag in HTML source.
  • Medium: Inspect JavaScript source.
  • Hard: Decode encoded data.

Easy

The flag is hidden in the page source.

Medium

The flag is hidden in the source, not in HTML comments.

Hard

The flag is encoded in the source code.

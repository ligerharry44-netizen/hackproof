Challenge 6 – URL Parameters / IDOR

Challenge Description

This website uses URL parameters to load user data and pages. Sometimes developers do not properly validate user input or check authorization. Try manipulating URL parameters to access hidden pages, admin functionality, or other user accounts.

Objectives

  • Easy: Modify the id parameter to find hidden data.
  • Medium: Discover hidden URL parameters.
  • Hard: Access another user's profile (IDOR vulnerability).

Easy

The website loads pages using a URL parameter called id. Try changing the id value.

Medium

The website might be using hidden URL parameters to control access. Try adding new parameters.

Hard

You can view profiles using a URL parameter. Try accessing another user's profile.

Challenge 5 – Files

Challenge Description

Developers sometimes leave backup files, hidden directories, or configuration files on the server. Attackers often search for these files to find sensitive information such as passwords or flags. Try to discover hidden files and retrieve the flags.

Objectives

  • Easy: Find a backup file on the server.
  • Medium: Discover a hidden directory.
  • Hard: Locate an exposed configuration file.

Easy

Developers sometimes leave backup files.

Medium

Hidden directories might contain files.

Hard

Configuration files may expose secrets.

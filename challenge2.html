Challenge 2 – robots.txt

Challenge Description

Websites often use a file called robots.txt to tell search engines which pages should not be indexed. Sometimes developers accidentally expose hidden directories or sensitive pages in this file. Attackers often check robots.txt to discover hidden paths.

Objectives

  • Easy: Find the robots.txt file and locate the flag.
  • Medium: Use robots.txt to discover a hidden page.
  • Hard: Find and decode an encoded flag on the hidden page.

Easy

Check the robots.txt file.

Medium

robots.txt might reveal hidden pages.

Hard

The flag is encoded on a hidden page.
